# 安装、升级与回退

> v0.3.3：看板显示期间默认保持唤醒；手动休眠后暂停更新，唤醒后恢复。周期 RTC 唤醒默认关闭。联网管理和自动关闭 Wi-Fi 均需主动开启，且仅关闭插件自己开启的无线电。升级请整体替换插件目录，runtime.lua 已不再使用。

[English](UPGRADE.md)

## 安装 v0.3.3

1. 从 Releases 下载 `ShawnKanban-0.3.3.zip` 和 `SHA256SUMS`。
2. 退出 KOReader，USB 连接 Kindle。在电脑上备份 `koreader/plugins/KindleDash.koplugin/` 和 `koreader/settings/kindledash.lua`。
3. 将安装包里的完整插件文件夹覆盖到 `koreader/plugins`。main.lua 和 sha256.lua 两个文件缺一不可，不能只复制 main.lua。
4. 安全弹出并重启 KOReader，打开工具 → DayPane → 设置／测试图片。
5. 在 Language / 语言 中选择中文；检查设备状态中的屏幕尺寸和图片时间。

已有地址、语言配置会保留，你的中文设置不变。新用户不再默认连接 Shawn 的局域网 IP。公共图源仍是个人配置的示例；更换城市、时区、单位、布局时，使用 Pages 的 `/setup/` 页面（或本地打开 `web/setup/index.html`），导入原配置并下载 config.json，放到自己的生成端。表单不上传数据，也不会修改公共示例图。

自动刷新开关现在会保存。自定义 PNG 地址继续兼容，但无法知道真实生成时间；要使用校验和与内容年龄，请填写 v1 协议的 manifest 地址。

## 常驻与省电设置

默认不强制开关 Wi-Fi。启用“更新时连接 Wi-Fi”后，由 KOReader 为看板恢复连接。“关闭看板开启的 Wi-Fi”只会关闭本轮请求前处于关闭状态、由看板开启的网络；原本已连接的网络保持不变。失败后按1、2、4、8、16、30分钟退避，成功后恢复正常间隔。

夜间降频使用设备时区，在23:00–07:00把自动刷新间隔提高到至少2小时；生成端时区单独设置。刷新间隔可设5–1440分钟；更频繁取图不会让公共半小时图源更快生成。

看板仍通过保持设备运行实现常驻。“实验：单次 RTC 唤醒测试”会在确认后使用 KOReader 接口安排一次2分钟闹钟并休眠，不开启循环，默认不运行。需要真机看护；未唤醒时使用电源键恢复。日志出现闹钟回调并不证明图片已经显示成功。当前不承诺深度休眠稳定性或续航时长。

## 诊断与验收

设备状态显示图源、内容生成时间、下载时间、最近尝试、错误和下次尝试。`settings/kindledash-health.json` 最多保留192条本地事件，并在可读时记录电量，不上传遥测。

实测正常取图、飞行模式、错误图源、电源键休眠恢复及退出。失败时应保留旧画面。省电实验需记录48小时刷新成功率和耗电；云端监测不能确认物理屏幕。

## 回退

退出 KOReader，用备份完整恢复插件目录；需要时恢复备份的设置文件，再重启。升级不需要删除设置或缓存。Releases 为可安装版本，main 为开发分支；插件包不包含你的生成端配置和生成图片。
