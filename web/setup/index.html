Install / 安装

  1. Download the plugin ZIP from GitHub Releases. / 下载插件安装包。
  2. Exit KOReader, back up the old plugin and copy the new folder to koreader/plugins. / 退出、备份并覆盖插件。
  3. Restart KOReader → Tools → DayPane → Setup / test image. / 重启后设置图源并测试。

Put config.json in your own renderer repository or set SHAWN_CONFIG to its local path. It does not personalize the public demo URL. / 将配置放到自己的生成端；公共示例图不会因下载配置而改变。
